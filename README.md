# BÀI THUYẾT TRÌNH TƯƠNG TÁC: TƯ TƯỞNG HỒ CHÍ MINH (CHƯƠNG 3)

Dự án slide thuyết trình tương tác đa chiều môn **Tư tưởng Hồ Chí Minh — Chương 3: Tư tưởng về độc lập dân tộc và chủ nghĩa xã hội**.

## 🌟 Tính Năng Nổi Bật
- **Thiết kế Neobrutalism hiện đại**: Trực quan, ấn tượng, tối ưu trải nghiệm thuyết trình và tương tác trong lớp học.
- **100% Tiếng Việt chuẩn mực**: Chuẩn thuật ngữ giáo trình và văn kiện lịch sử Đảng.
- **Hệ thống 4 chặng nội dung & tương tác thực tế**:
  1. **Chặng 1 (Mục 3.1.1 — Độc lập dân tộc)**: Bản đồ 4 tư liệu lịch sử qua 3 bước (Quan sát ảnh ➔ Thử thách nhận thức ➔ Đúc kết bài học).
  2. **Chặng 2 (Mục 3.1.2 — Cách mạng giải phóng dân tộc)**: Hoạch định 5 quyết sách chiến lược (Đại hội Tours 1920, Đại đoàn kết, Đường Kách Mệnh 1927, Đội VNTTGPA, Luận điểm "con đỉa hai vòi").
  3. **Chặng 3 (Mục 3.2.1 — Bản chất chủ nghĩa xã hội)**: Mô phỏng phân bổ 100 Điểm Nguồn Lực theo thời gian thực giữa 4 trụ cột (Chính trị, Kinh tế, Văn hóa, Xã hội).
  4. **Chặng 4 (Mục 3.2.2 — Xây dựng CNXH ở Việt Nam)**: Giải quyết 4 bài toán thực tiễn lịch sử (Bỏ qua TBCN, cơ cấu nông - công nghiệp, động lực con người, chống giặc nội xâm).
  5. **Diễn đàn Tranh luận (Slide 10)**: Bình chọn tương tác: CNXH là mục đích hay phương tiện?
  6. **Game Ghép Nối Mạch Biện Chứng (Slide 11)**: Thử thách ghép 4 mắt xích tư tưởng để mở khóa Đích đến tối thượng của Bác.
- **100% Ảnh tư liệu lịch sử thực tế**: Lưu trữ nội bộ trong `assets/images/`.

## 🚀 Hướng Dẫn Chạy & Deploy

### Chạy cục bộ (Local)
Mở trực tiếp file `index.html` trên bất kỳ trình duyệt nào, hoặc khởi chạy một HTTP server nhẹ:
```bash
# Sử dụng Python
python -m http.server 3000

# Hoặc sử dụng npx serve
npx serve .
```

### Triển khai lên Vercel
Dự án đã được cấu hình sẵn cho Vercel (`vercel.json`):
1. Kết nối kho lưu trữ GitHub `MTV-2602/HCM202` vào Vercel.
2. Vercel sẽ tự động phát hiện và triển khai dạng **Static Site** chỉ trong vài giây!
